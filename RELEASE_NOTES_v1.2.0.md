# TouchMaster Pro v1.2.0 — ilk hedef görünürlüğü

İlk hedef eklendikten sonra overlay pencere olayları nedeniyle kaybolabilen hedef marker’ı düzeltildi. Servis artık ekrandaki marker sayısını kayıtlı hedef sayısıyla karşılaştırıyor; eksik marker tespit edildiğinde otomatik olarak yeniden çiziyor. İlk hedef ekleme sonrasında kısa gecikmeli görünürlük kontrolü de eklendi.
